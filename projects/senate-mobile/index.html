Senate
Mobile

Zero input. Full context.
00  —  Brief
The Problem

Tracking health and habits means opening five apps, entering numbers manually, and still missing the context that makes any of it useful. Data without intelligence is noise. You end up ignoring all of it.

The Build

A personal AI app built for Android. Zero manual entry — steps, sleep, and activity pull automatically from Health Connect and Strava. Havi, a Claude-powered assistant, is the primary interface. You talk to it. It knows your data.

01  —  How it works
01 Connect
Sources Link Health Connect and Strava. Steps, sleep, heart rate, and activity flow in automatically.
02 Ask
Havi Talk to the Claude-powered assistant. It reads your health data and responds in context.
03 Review
Dashboard Stats, streaks, Notion calendar events, and Strava activity. All in one place.
04 Set
Alerts Push reminders with one-tap notification actions. Medicine, water, habits. No app open required.
02  —  Capabilities
01 Havi AI Assistant Claude-powered chatbot with full access to your health data. Ask questions, get summaries, understand trends. Plain language.
02 Zero-Entry Data Health Connect and Strava integration. Steps, sleep, heart rate, weight, and activity auto-pulled. No manual input.
03 Smart Reminders Push notifications with one-tap action buttons. Dismiss, complete, or snooze without opening the app. Habit streaks tracked automatically.
04 Notion Calendar Events pulled from Notion into the dashboard. Havi can reference your schedule when answering questions.
05 Secure by Default API keys stored in expo-secure-store. No cloud sync of personal health data. Everything stays on-device.
06 Haptic Feedback Haptics throughout: reminders, settings saves, onboarding. The app responds to every interaction with physical confirmation.
03  —  Stack
React Native Expo SDK 55 TypeScript expo-router Zustand @anthropic-ai/sdk Health Connect Strava API expo-notifications expo-haptics expo-secure-store Notion API
Current Status

Builds and runs stably on Android. All core features are working. Health Connect integration is in progress. Personal use only. Not publicly released.
